MailSeer 0.2.0 — Windows x64

Released: July 2026

MailSeer 0.2.0 is a major Windows release focused on stronger local retrieval, Ask MailSeer, mailbox intelligence, reliability, and release hardening.

Highlights

  • Private local-first search across Gmail, Yahoo, and Outlook.
  • Semantic, hybrid, and lexical search with smart routing.
  • Optional Enhanced Ranking for stronger retrieval precision.
  • Ask MailSeer with optional local AI and local RAG.
  • Improved calendar, meetings, subscriptions, commerce, finance, work/office, documents, security-alert, and task intelligence.
  • Single-instance protection and hardened packaged backend lifecycle.
  • Signed Windows x64 installer and portable ZIP.

Local AI setup

Semantic Search is ready immediately. For the complete experience, install Enhanced Ranking and Local AI from the app's Local AI panel.

System requirements

Windows 11 on a 64-bit Intel or AMD PC (x64). Windows on Arm is not supported in this release.
